# VanillaWeatherPlus - Bug Report

This repository is only the issue tracker for the **Vanilla Weather Plus** mod https://modrinth.com/mod/vanilla-weather-plus. No code is uploaded here; it’s just for reporting bugs and suggestions.

## How to report a bug

Before opening a new issue, check the [existing issues](../../issues) to see if someone has already reported the same thing.

When opening an issue, include if you can:

- **Minecraft version** (e.g., 1.21.1)
- **Mod version** (e.g., v8)
- **Mod loader** (NeoForge/Forge/Fabric) and its version
- **Problem description**: what happened and what you expected to happen
- **Steps to reproduce it**
- **Log or crash report** if the game closed (upload it as a file or paste it in a [gist](https://gist.github.com))
- Screenshots or video if it helps understand the bug

## Status

I review issues when I can. No guaranteed response times.
